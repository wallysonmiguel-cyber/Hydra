# 🔵⚪🟡 Hydra Sistems

**Clique em [Releases](../../releases)** e baixe os APKs mais recentes do **Hydra Autentication** e do **Hydra Pay**.

---

### 🚀 Passo a Passo para Acesso:

1. Acesse o **Hydra Pay** e faça seu cadastro seguindo o fluxo.
2. Quando seu cadastro estiver aprovado, acesse o **Hydra Autentication** e faça login com as mesmas credenciais cadastradas no Hydra Pay.
3. O sistema pedirá para você confirmar sua identidade. Siga o fluxo.
4. Quando estiver na tela de início (Home), **feche o app**.
5. Entre novamente no **Hydra Pay** e faça login com suas credenciais. O app solicitará um código de autenticação de 6 dígitos.
6. Acesse o **Hydra Autentication**, copie o código e cole-o no **Hydra Pay**. 
   > ⚠️ **Atenção:** O código de autenticação tem validade de apenas 30 segundos.

✅ **Feito isso, seu cadastro e login no Hydra Pay estarão prontos!**
