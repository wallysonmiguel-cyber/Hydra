# Hydra Sistems
Clique em Releases baixe os APKs Mais recente do Hydra Autentication e do Hydra Pay.
Acesse o Hydra Pay, Faça seu cadastro seguindo o fluxo, quando seu cadastro estiver aprovado acesse o Hydra Autentication e faça login com as mesmas credenciais cadastradas no Hydra Pay, o sistema pedira para você confirmar sua identidade, siga o fluxo, quando estiver na tela de inicio (Home), feche o app e entre no Hydra Pay e faça login com suas credenciais, o app solicitará um código de autenticação de 6 digitos, acesse o Hyra Autentication copie o codigo e cole-o no Hydra Pay (O código tem validade de 30 segundos), Feito isso, seu cadastro e login no Hydra Pay estará Pronto
